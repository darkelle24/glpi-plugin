# Vérification des API et sources

Vérification du 26 octobre 2026, sur le tag officiel **12.0.0**, commit `cd812fbc82eaa8d0356d0fb650842069c1c18f4e`. Les liens pointent sur des sources primaires ; aucun hook hypothétique de type `pre_mailcollector` n'est utilisé.

| Point vérifié | Source et conséquence |
|---|---|
| Origine du suivi mail | [MailCollector.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/MailCollector.php#L1041) : `buildTicket()` ajoute `_mailgate`, puis `_auto_import`. Lors de la collecte et de la reprise des mails rejetés, le tableau est transmis à `ITILFollowup::add()` avec `itemtype=Ticket` et `items_id`. |
| Moment du nettoyage | [CommonDBTM.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/CommonDBTM.php#L1348) : `PRE_ITEM_ADD` intervient sur `$item->input` avant `prepareInputForAdd()`, les filtres et l'écriture. Pas de modification après enregistrement ni de boucle de mise à jour. |
| Déclaration du hook | [Hooks.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/Glpi/Plugin/Hooks.php#L452), [Plugin::doHook](https://github.com/glpi-project/glpi/blob/12.0.0/src/Plugin.php#L1779) : enregistrement par classe `ITILFollowup`, callback recevant l'objet. |
| Validation du suivi | [ITILFollowup.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/ITILFollowup.php#L378) : GLPI garde ses validations habituelles après le hook. Le plugin ne neutralise pas les droits ni la gestion des notifications. |
| Marqueurs de réponse | [NotificationTargetTicket.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/NotificationTargetTicket.php#L43) : `HEADERTAG` et `FOOTERTAG`. Le collecteur les traite déjà en amont ; le plugin protège leurs occurrences restantes. |
| Images incorporées | [Ticket::convertContentForTicket](https://github.com/glpi-project/glpi/blob/12.0.0/src/Ticket.php#L5382) remplace les images jointes par des balises `img` avec un identifiant et sans `src`. Ces placeholders sont protégés, ainsi que les liens/images utilisant `document.send.php`. |
| Configuration native | [Config.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/Config.php#L1326) : `getConfigurationValues`, `setConfigurationValues`, `deleteConfigurationValues`. Contexte propre au plugin et liste explicite des clés à la désinstallation. |
| Interface du plugin | [Plugin.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/Plugin.php#L2843) : `CONFIG_PAGE` construit l'URL `/plugins/<clé>/<page>`. [LegacyRouterListener.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/Glpi/Kernel/Listener/RequestListener/LegacyRouterListener.php) prend en charge les pages PHP ; le noyau GLPI est déjà chargé. `inc/includes.php` est obsolète en 12. |
| Sécurité des formulaires | [CheckCsrfListener.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/Glpi/Kernel/Listener/ControllerListener/CheckCsrfListener.php), [Session.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/Session.php#L1762) : protection d'origine par GLPI ; anciennes méthodes CSRF dépréciées et sans effet. Le plugin ajoute un jeton de session propre et vérifie `Session::checkRight('config', UPDATE)`. |
| Moteur CSS disponible | [composer.json](https://github.com/glpi-project/glpi/blob/12.0.0/composer.json) et [composer.lock](https://github.com/glpi-project/glpi/blob/12.0.0/composer.lock) : PHP ≥ 8.3, DOM et Symfony CssSelector `^7.4`, verrouillé à `v7.4.18` (`fecf40067fc8d8880ea87b8ac227600b9aadd1d0`). [Documentation Symfony 7.4](https://symfony.com/doc/7.4/components/css_selector.html) et [sources exactes](https://github.com/symfony/css-selector/tree/fecf40067fc8d8880ea87b8ac227600b9aadd1d0) pour les limitations des sélecteurs. |
| Installation en console | [InstallCommand.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/Glpi/Console/Plugin/InstallCommand.php), [ActivateCommand.php](https://github.com/glpi-project/glpi/blob/12.0.0/src/Glpi/Console/Plugin/ActivateCommand.php) : commandes `plugin:install` et `plugin:activate`. |
| Docker | [Image officielle](https://github.com/glpi-project/docker-images/blob/main/README.md), [exemple Compose](https://github.com/glpi-project/docker-images/blob/main/docker-compose.example.yml) : volume `/var/glpi`, plugins personnalisés `/var/www/glpi/plugins`, variables de base et ordonnanceur intégré. Le guide est adapté au montage d'un plugin dans une instance existante. |
| TrueNAS SCALE | [Installation des Custom Apps](https://apps.truenas.com/managing-apps/installing-custom-apps/) : installation via YAML Docker Compose depuis Apps. Les écrans exacts dépendent de la version. |

Le ciblage `_mailgate` est confirmé dans la version auditée mais reste un champ interne du collecteur ; revalider ce contrat après mise à jour de GLPI. La déclaration de compatibilité exclut 12.1 et ultérieur.

Complément 1.2.0 : `MailCollector.php` transmet `_mailgate` et `_auto_import` à `Ticket::add()` pour une création initiale et à `ITILFollowup::add()` pour une réponse. Le hook `PRE_ITEM_ADD` est enregistré pour les deux classes, mais la suppression des signatures reste limitée aux suivis. Le fichier [css/includes/components/_richtext.scss](https://github.com/glpi-project/glpi/blob/12.0.0/css/includes/components/_richtext.scss) décrit `.rich_text_container`. La normalisation retire les couleurs d'origine pour laisser le thème du lecteur s'appliquer ; elle ne lit pas les préférences du compte exécutant le collecteur.
